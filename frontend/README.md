# 🍕 TRI FRATELLI FRONTEND
## Sobre o Projeto
Interface moderna desenvolvida em React + TypeScript, conectada ao backend via API REST e integrada ao fluxo completo de autenticação.

Link do projeto: https://cardapio-digital-qnfh.vercel.app/
##  Tecnologias
![React](https://skillicons.dev/icons?i=react)
![Typescript](https://skillicons.dev/icons?i=typescript)
![Vite](https://skillicons.dev/icons?i=vite)
![Css3](https://skillicons.dev/icons?i=css)
![Axios](https://skillicons.dev/icons?i=axios)
- React – Biblioteca para construção de interfaces interativas  
- TypeScript – Tipagem estática e maior segurança no código  
- Vite – Ferramenta de build e desenvolvimento otimizada  
- Axios – Cliente HTTP para integração com a API  
- CSS3 – Estilização moderna e responsiva  
### Rodando o Projeto
```
git clone https://github.com/DSW-II-FullStackProject/Cardapio-Digital.git
cd frontend
npm install
npm run dev
```
